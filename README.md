# Green Box – A smart garbage bin that automatically classifies waste based on IoT and AI.

Bài tập nhóm môn IoT và ứng dụng PTITHCM

## Hướng dẫn tải và chạy

- Clone repo

```commandline
git clone https://github.com/TuLe142857/greenbox.git
```

-  Copy file esp32-cam/src/config.example.h thành file config.h 
 và điền các giá trị cần thiết theo mẫu

```commandline
cd greenbox
cp esp32-cam/src/config.example.h esp32-cam/src/config.h
```

- Nạp code cho esp32-cam và arduino, chạy server
